## 閲覧方法

3. `統計的学習の基礎.html` をブラウザーで開きます。

HTMLファイルはGitHub上の通常のファイル表示ではなく、ダウンロードして閲覧してください。外部フォントの読み込みにはインターネット接続を使用します。
